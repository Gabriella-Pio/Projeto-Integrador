# 🎭 Sistema de Venda de Ingressos - Projeto Integrador

Este repositório contém o código e a documentação do sistema desenvolvido como Projeto Integrador do 1º semestre de 2024, pelos alunos do curso de Engenharia de Software da Faculdade SENAI FATESG. O projeto foi idealizado para atender à necessidade do **Teatro ABC** em modernizar e automatizar o processo de venda de ingressos.

## 📌 Objetivo do Projeto

Desenvolver um sistema em **Java (Desktop)** que permita:

- Comprar ingressos para diferentes peças, sessões e áreas do teatro;
- Imprimir comprovantes dos ingressos adquiridos;
- Gerar estatísticas detalhadas de vendas, como peças mais vendidas e sessões mais lucrativas.

## 🧾 Funcionalidades

✅ **Compra de Ingressos**  
- Cadastro via CPF  
- Escolha da peça (3 disponíveis)  
- Escolha de sessão: manhã, tarde ou noite  
- Escolha de área e poltrona  
- Preços por área:  
  - Plateia A: R$ 40,00  
  - Plateia B: R$ 60,00  
  - Camarote: R$ 80,00  
  - Frisa: R$ 120,00  
  - Balcão Nobre: R$ 250,00

✅ **Impressão de Ingressos**  
- Visualização e impressão do comprovante com base no CPF do cliente

✅ **Estatísticas de Vendas**  
- Peça mais e menos vendida  
- Sessão com maior e menor ocupação  
- Peça mais e menos lucrativa  
- Lucro médio por peça

## 📊 Resultado Esperado

Um sistema funcional, intuitivo e estável que:

- Melhora a experiência do usuário na compra de ingressos;
- Facilita a gestão de vendas do Teatro ABC;
- Fornece relatórios úteis para a administração do teatro.
